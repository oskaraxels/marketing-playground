# Marketing Taste Playground

A static, single-page training site to build marketing *taste*: pick the winner, rate good vs bad, diagnose what's missing, study teardowns, and write your own copy — mostly Meta ads, then cold email.

- Live: https://oskaraxels.github.io/marketing-playground/
- Data: `data/tasks.js` (generated by `research/build.py` from `research/c_*.py` + the Upworthy Research Archive CSV), also `data/tasks.json`.
- Every task has an evidence label and a source link. See `SOURCES.md`.
- Progress is stored only in your browser (localStorage). Export/import JSON from the home page.
- Tests: `python3 tests/test_site.py <base_url> <label>` (Playwright + /usr/bin/google-chrome; 1366x768 and 1440x900; link check).

Keyboard: 1/2 pick · Enter reveal/next · ←/→ · M mark done · F focus · Esc exit focus · S outline.
